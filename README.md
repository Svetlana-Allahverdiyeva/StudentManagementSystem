# Student Management System

## About the Project
Student Management System is a Python-based application
for managing student information.

## Features
- Add Student
- Show All Students
- Search Student
- Update Student
- Delete Student

## Technologies
- Python
- JSON
- Git
- GitHub

## Project Structure

```text
StudentManagementSystem/
│
├── database.py
├── main.py
├── student.py
├── students.json
├── utils.py
└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run main.py.

## Data Storage
Student information is stored in students.json.
